# Beauty-App

A premium, responsive beauty-tech landing page for Aura, built with React, Vite/vinext, Tailwind CSS, Lucide React, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Live site: https://aura-beauty.noble-hare-1805.chatgpt.site/
